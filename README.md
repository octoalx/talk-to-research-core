# talk-to-research-core

Ядро MVP: локальная среда на Mac, которая отвечает по договорам и праву
Республики Беларусь со ссылками и механической проверкой цитат.

- Что строим и почему: [octoalx/talk-to-research](https://github.com/octoalx/talk-to-research) (журнал: `spec/`, `decisions/`)
- План по вехам M0–M10: [docs/PLAN.md](docs/PLAN.md)
- Правила для ИИ-агента и людей: [AGENTS.md](AGENTS.md)
- Проверочный набор: [eval/testset-by/](eval/testset-by/)

Кода пока нет: работа начинается с вехи M0.

## Как начать (на MacBook)

1. Получить доступ к обоим репозиториям на GitHub (журнал и этот).
2. Склонировать этот репозиторий.
3. Открыть папку в своём агенте (Claude Code, Codex, Cursor) и сказать:
   «Прочитай AGENTS.md и docs/PLAN.md, выполни следующую невыполненную веху».
4. Агент работает в ветке и открывает PR; сливает человек.
5. Замеры кладутся в `docs/results/`, вопросы к плану — в `docs/feedback.md`.

## Где что живёт

Всё важное — только на GitHub (decisions/027 журнала). Решения о том,
что строим, принимаются в журнале; здесь — только код, замеры и вопросы.
Dark Factory — один из возможных исполнителей, код от неё не зависит
(`docs/factory.md`).
