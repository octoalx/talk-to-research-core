# Проверочный набор: право Республики Беларусь

Создан 2026-10-05 для пилота ([decisions/002](../../decisions/002-пилот-беларусь.md)).

- `contracts/` — 12 вымышленных документов компании ООО «Северный Луч»
  (покупатель запчастей, арендует офис, нанимает подрядчиков).
  Все организации, люди и реквизиты выдуманы.
- `questions.md` — вопросы к системе с правильными ответами. В части
  документов специально заложены проблемы, чтобы проверять сценарии
  из `spec/02-requirements.md`.

Как пользоваться: загрузить `contracts/` в коллекцию «свои документы»,
акты из `../belarus-pilot.md` — в «юридическую базу», задать вопросы и
сравнить ответы и ссылки с эталоном.

«Сегодня» для всех вопросов: **5 октября 2026 г.**

Ответы, завязанные на законодательство (помечены ⚖️), составлены по
вторичным источникам и должны быть сверены с текстами актов до
использования как эталона.
